# GBARunner3 — B/Y to A/B Remap (v1.0, DSi test build)

Unofficial, AI-assisted GBARunner3 modification for a more comfortable GBA button layout on Nintendo DS-family hardware.

**Button mapping:** Nintendo DS **B → GBA A** and Nintendo DS **Y → GBA B**. D-pad, L, R, Start and Select are unchanged.

**Tested:** One Nintendo DSi with DSpico / Pico Launcher. The repository owner confirmed that the remapping worked on their console. Other DS models and all games have not been tested.

**Installation:** Back up your SD and original `/_pico/emulators/GBARunner3.nds`, then copy the modified executable to that location. Restore the original if problems occur.

**Want to compile it yourself?** Follow [`BUILD.md`](BUILD.md) in the repository and run the GitHub Actions workflow to generate your own `.nds`.

**Credits:** Original GBARunner3 by Gericom; experimental Y-to-B fork by dhorlick. The additional B/Y-to-A/B remap and compilation instructions were prepared with ChatGPT assistance.

No games, commercial ROMs or BIOS files are bundled.
