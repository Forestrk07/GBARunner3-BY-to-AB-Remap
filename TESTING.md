# Compatibility and Testing

## Tested setup

- **Console:** Nintendo DSi
- **Launcher:** DSpico / Pico Launcher
- **Program:** Custom GBARunner3 button-remapping build
- **Result:** The remapped buttons worked as intended during a real-console test.

## Button mapping

| Nintendo DS button | GBA input |
| --- | --- |
| B | A |
| Y | B |
| D-pad, L, R, Start, Select | Unchanged |

## Important notes

- This build has only been tested by the repository owner on one Nintendo DSi using DSpico / Pico Launcher.
- Nintendo DS (original), DS Lite, and other systems have **not** been verified.
- Compatibility with every GBA game has **not** been verified.
- The successful test does not guarantee that the build will behave identically on other devices.

## Display settings

The tester also uses `centerOffsetX: 6` in their local `gbarunner3.json` to visually center the image. This is a separate personal display setting, not part of the button remap, and may vary across setups.
